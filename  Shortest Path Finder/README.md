# Shortest Path Finder

Currently contains an NBA scoreboard / stats client using the BallDon'tLie API.

## Requirements
```bash
pip install requests
```

## Setup
1. Get a free API key from https://app.balldontlie.io
2. Put your key in `API_KEY` inside `project.py`

## Notes
- Free accounts can use `/games`
- `/stats` requires a paid ALL-STAR (or higher) plan

## Run
```bash
python project.py
```
