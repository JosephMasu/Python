# 05 Exercises

A collection of small console apps and practice problems.

## Files
- `calculator.py` — basic calculator
- `choose_your_own_venture.py` — text adventure
- `compoundcalculator.py` — compound interest
- `concessionstand.py` — concession stand menu
- `guessingnumber.py` — number guessing game
- `madlibs.py` — Mad Libs story
- `one.py` — rectangle area
- `rockscissors.py` — rock-paper-scissors
- `shoppingcart.py` — shopping cart
- `temperaturecovertor.py` — temperature converter
- `timercountdown.py` — countdown timer
- `two.py` — extra exercise
- `validateuserinputs.py` — input validation
- `weightconvertor.py` — weight converter

## Run
```bash
python calculator.py
```
