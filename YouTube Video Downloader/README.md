# YouTube Video Downloader

Downloads a YouTube video to a folder you choose (Tkinter folder picker).

## Requirements
```bash
pip install pytubefix
```

If downloads fail with HTTP 400 / bot detection, switch to `yt-dlp` and install `ffmpeg` for best quality:
```bash
pip install yt-dlp
brew install ffmpeg
```

## Run
```bash
python project.py
```

Paste a video URL, then choose a save folder (for example Downloads).
